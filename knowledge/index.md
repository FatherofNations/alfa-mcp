# proto-forge knowledge — оглавление

База знаний по разработке интерактивных прототипов по Figma-макетам.
Каждый документ — конденсат реального опыта. Читай нужный ПЕРЕД задачей.

| Ресурс | Когда читать |
|---|---|
| `proto://knowledge/figma-import` | перед разбором макета: выгрузка данных/ассетов из Figma, все грабли |
| `proto://knowledge/pixel-perfect` | перед вёрсткой: методика точного переноса, бленд-диффы |
| `proto://knowledge/animation-canon` | перед любым моушеном: канонические кривые/тайминги, 12 рецептов |
| `proto://knowledge/react-patterns` | перенос статики в Next.js: партиалы, StrictMode, оверлеи |
| `proto://knowledge/project-structure` | что где лежит в скаффолд-проекте, правила слоёв |
| `proto://knowledge/tools-panel` | панель прототипа: рамка-обрезка, board/board-body, свопы |
| `proto://knowledge/deep-links` | состояние в URL: replaceState, чтение на маунте |
| `proto://knowledge/deploy-vercel` | перед деплоем: framework preset, protection, promote |
| `proto://knowledge/verification` | перед сдачей: parity-QA чек-лист, программный проклик |
| `proto://knowledge/design-system` | шрифты/иконки/токены core-ds |

Типовой цикл «новый дашборд по фрейму»: figma-import → pixel-perfect →
(вёрстка) → animation-canon → verification → deploy-vercel.
