# tools-panel — панель прототипа

> Чёрная панель справа: селектор дашбордов, тогглы вариантов, свитчи
> состояний. Инфраструктура «покрутить прототип» для показов.

## Архитектура

- **Контекст в root layout** (`ToolsProvider` оборачивает `children`) —
  переживает смену роута: панель не закрывается при свопе дашбордов.
- Состояние: `dashboard` (вычисляется из pathname), `panelOpen`,
  прикладные состояния прототипа (варианты, тогглы стека и т.п.).
- FAB (48px, круглый, иконка слайдеров морфится в крестик) открывает
  панель; **Esc закрывает** (слушатель вешается только при открытой).

## Панель (ширина 320)

```
.twk        — fixed справа, translateX(100%) → none, 0.55s структурная кривая
.twk-cards  — грид карточек-селектора дашбордов (активная подсвечена)
.twk-sec    — заголовок секции (12px, 40% white)
.twk-row    — строка «лейбл + свитч», 48px, разделители 7% white
.twk-sw     — iOS-свитч (зелёный трек включённого)
.twk-fab    — плавающая кнопка, right: calc(24px + var(--twk))
```

`body { --twk: 0px }`, `body.twk-open { --twk: 320px }` — переменная
двигает FAB и (если нужно) поджимает контент.

## Рамка-обрезка (ключевой приём)

При открытой панели вьюпорт дашборда **обрезается**, контент остаётся 1:1
(НЕ масштабируется), вокруг — тёмные поля:

```css
.board {                       /* фрейм дашборда, всегда в DOM */
  position: fixed; inset: 0;
  background: var(--page-bg);
  clip-path: inset(0 round 0);
  transition: clip-path 0.55s cubic-bezier(0.32, 0.72, 0, 1);
}
/* панель 320 + зазор 12 = 332 справа; остальные отступы 12 */
body.twk-open .board { clip-path: inset(12px 332px 12px 12px round 20px); }

html { transition: background-color 0.5s ease; }
html.twk-open { background: #0c0c0f; }  /* поля вокруг обрезанного борда */
```

Нюансы:

- `clip-path` клипает **и fixed-потомков** — обрезается весь дашборд.
- Фон полей — класс на `html`: всё содержимое body — fixed, поэтому фон
  body экран не заливает. Класс `twk-open` ставить на **оба**:
  `document.body` и `document.documentElement`.

## Разделение «фрейм / наполнение»

```
.board        — ПОДЛОЖКА + обрезка. Статична, при свопах НЕ анимируется.
.board-body   — НАПОЛНЕНИЕ: fixed inset:0, скролл-контейнер
                (overflow-y:auto). Анимируется при свопах (.dash-out).
```

Смысл: при свопе дашбордов растворяется только наполнение, светлая
подложка и рамка стоят неподвижно — «содержимое сменилось внутри рамки».
`fixed inset:0` на `.board-body` обязателен: во время `filter` он
становится containing block для fixed-потомков, и только совпадение его
геометрии с вьюпортом не ломает сайдбары (см. react-patterns).

## Смена содержимого панели

Динамическая секция панели ремаунтится по `key` (смена дашборда/варианта):

```tsx
<div className="twk-dyn" key={dashboard}>…</div>
```

```css
.twk-dyn > * {
  opacity: 0; filter: blur(12px); transform: translateY(10px);
  animation: twk-dyn-in 0.5s cubic-bezier(0.25, 0.1, 0.25, 1) forwards;
  animation-delay: calc(60ms + var(--i, 0) * 30ms);
}
@keyframes twk-dyn-in { to { opacity: 1; filter: blur(0); transform: none; } }
```

`--i` — через `nth-child` (в шаблоне до 12 детей).

## Своп дашбордов из карточки

Карточка зовёт `swapTo(route)` из контекста:

1. `.board-body` получает `.dash-out` (канон скрытия: 0.22s ease-in в блюр);
2. по таймеру `SWAP_OUT_MS = 250` — `router.push(route)` (наполнение уже
   полностью прозрачно, скачка нет);
3. по приезде нового роута класс снимается через двойной rAF — новое
   наполнение проявляется по канону появления (0.5s + задержка 120ms);
4. страховка: если навигация не случилась за 2.5s (оффлайн) — вернуть борд.

Оба/все роуты префетчить (`router.prefetch`) — под блюром не ждём сеть.
