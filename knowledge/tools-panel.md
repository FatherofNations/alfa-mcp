# Optional prototype controls
Add the tools panel only when requested. Preserve the existing stack and established controls.
Keep panel state separate from page content and motion state. Do not remount the page on every inspector change.
Use an accessible dialog/panel with keyboard control, Escape, focus restoration and intentional scroll behavior.
Keep fixed overlays outside transformed ancestors.
Define page-switch choreography through alfa://knowledge/animation-canon; no universal blur, timer or fixed viewport wrapper is required.
Use completion signals, asset readiness and explicit rapid-input behavior. Preserve valid content when navigation fails.
Check direct links, open/close, changing controls during motion and reduced motion.
